## Datasets (not included)

The datasets are not stored in this repository and must be downloaded separately:

- **ISIC 2019:** https://challenge.isic-archive.com/data/
- **PAD-UFES-20:** https://data.mendeley.com/datasets/zr7vgbcyr2/1
- **DDI (Diverse Dermatology Images):** https://ddi-dataset.github.io/

## Installing dependencies

The notebooks were run in Google Colab. To run them elsewhere:

```
pip install -r requirements.txt
```

DermLIP weights are loaded from Hugging Face (`redlessone/DermLIP_ViT-B-16`).
